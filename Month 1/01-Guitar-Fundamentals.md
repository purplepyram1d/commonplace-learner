## 1. Parts of the guitar

```
    HEADSTOCK            NECK                          BODY
  ┌──────────┐┌──────────────────────────────┐  ╭───────────────────╮
  │ ○ ○ ○    ││ | | | | | | | | | | | | | |  │  │     ( sound  )    │
  │ tuners   ││ frets →                      │  │     (  hole  )  ▭ │ ← bridge
  │ ○ ○ ○    ││ | | | | | | | | | | | | | |  │  │                   │
  └──────────┘└──────────────────────────────┘  ╰───────────────────╯
            ↑ nut                    ↑ fretboard      ↑ saddle sits in the bridge
```

| Part | What it is | Why you care |
|---|---|---|
| **Headstock** | The top end, where the tuning pegs are | You tune here |
| **Tuning pegs / tuners / machine heads** | The knobs that tighten and loosen each string | Turning them changes pitch |
| **Nut** | The small white or black strip between the headstock and the fretboard | Strings rest on it. "Open" strings vibrate from here |
| **Neck** | The long wooden part | Your left hand lives here |
| **Fretboard / fingerboard** | The front face of the neck | You press strings against it |
| **Frets** | The metal strips across the fretboard | Pressing a string just behind a fret shortens it and raises the pitch. Fret 1 is closest to the nut |
| **Fret markers / inlays** | The dots on frets 3, 5, 7, 9, 12 (double dot) | Help you find your place |
| **Body** | The big hollow wooden box | It amplifies the sound |
| **Soundhole** | The round hole | The sound comes out here, and you strum near it |
| **Bridge** | The wooden piece glued to the body where the strings attach | Anchors the strings |
| **Saddle** | The white strip in the bridge | Transfers vibration to the body |
| **Bridge pins** | The pegs holding strings in the bridge (on most acoustics) | You remove them to change strings |
| **Pickguard** | The thin plastic plate below the soundhole | Protects the wood from pick scratches |
| **Strap buttons** | The knobs at the bottom of the body (and sometimes the heel) | Where a strap attaches |
| **Truss rod** | A metal rod inside the neck that controls how much it bows | **Don't adjust it yourself.** Let a shop do it |

## 2. String names and numbers

Hold the guitar in playing position and look down.

| String number | Note name | Position | Thickness | Pitch (scientific) |
|---|---|---|---|---|
| **6** | **E** (low E) | Closest to your face (top when you look down) | Thickest | E2 |
| **5** | **A** | | | A2 |
| **4** | **D** | | | D3 |
| **3** | **G** | | | G3 |
| **2** | **B** | | | B3 |
| **1** | **E** (high e) | Closest to the floor | Thinnest | E4 |

**Memory trick (6 → 1):** **E**ddie **A**te **D**ynamite, **G**ood **B**ye **E**ddie.
**Memory trick (1 → 6):** **E**very **B**oy **G**ets **D**inner **A**t **E**ight.

> The confusing part: the "top" string physically (closest to your face) is the **lowest** in pitch and is called **string 6**. "High" and "low" always refer to **pitch**, not physical position.

## 3. Tuning

**Tune every single time you pick up the guitar.** New strings stretch, temperature and humidity change, and strings slip. An out-of-tune guitar will also pull your singing out of tune, because you'll unconsciously match it.

### Standard tuning: E A D G B E (low to high)

### Method A: Clip-on tuner or app (use this one)
1. Clip the tuner to the headstock, or open the app and hold the phone near the guitar.
2. Pluck **one string** and let it ring. Pluck with medium force. Very hard picking makes the note go sharp at first.
3. The tuner shows a letter and a needle or bar:
   - **Flat** (needle left / "♭"): the note is too low → **tighten** the string
   - **Sharp** (needle right / "♯"): the note is too high → **loosen** the string
   - Centered and/or green: in tune
4. **Always tune UP to the note.** If you're sharp, loosen below the note, then tighten back up to it. This locks the string in the tuning peg and it'll hold pitch longer.
5. Tune all 6 strings, then **check all 6 again**, because tightening one string slightly changes the others (the neck flexes).
6. Make sure the tuner shows the **right letter**. If you're tuning the 5th string and it says "G#", you're way off. Find the right note before fine-tuning.

**Which way do I turn the peg?** On most acoustics, with the headstock facing you, turning the pegs **counter-clockwise tightens** (raises pitch) on both sides. But guitars vary, so **turn slowly while the string is ringing and watch the tuner.** If the pitch goes the wrong way, reverse. Never crank a peg many turns without plucking, because that's how strings snap.

### Method B: Relative tuning (backup; also great ear training)
If the low E is in tune (or you just want the guitar in tune with itself):
- Press string **6 at fret 5** → that note should match open string **5 (A)**
- Press string **5 at fret 5** → matches open string **4 (D)**
- Press string **4 at fret 5** → matches open string **3 (G)**
- Press string **3 at fret 4** ← **(fret 4, not 5, the one exception)** → matches open string **2 (B)**
- Press string **2 at fret 5** → matches open string **1 (e)**

When two notes almost match you'll hear a "wobble" or "beating." Adjust until the wobble slows down and disappears.

### Tuning checklist
- [ ] All 6 strings show the right letter and a centered needle
- [ ] Re-checked all 6
- [ ] Strum an open Em chord (see below). It should sound "right" and warm, not sour

## 4. Posture: how to sit and hold the guitar

Good posture prevents pain, makes chords easier, **and matters for singing**, because a collapsed chest restricts your breathing.

### Sitting (use this for all of Month 1)
1. Sit on the **front half of an armless chair**, with your feet flat on the floor about shoulder-width apart.
2. **Back tall**: imagine a string pulling the top of your head toward the ceiling. Don't lean back.
3. Rest the guitar's **waist** (the inward curve on the bottom of the body) on your **right thigh**.
4. The back of the guitar touches your stomach/chest and **tilts back only very slightly**. Don't tilt it way back to see the fretboard. Look over the top edge, or lean your head a little. (Peeking is fine; slouching is not.)
5. Your **right forearm** rests on the top edge of the body, near the elbow. This arm holds the guitar in place, not your left hand.
6. The neck points **slightly upward**, about 10–20° above horizontal. The headstock should be around shoulder height.
7. **Test:** take your left hand completely off the neck. The guitar should stay put. If it drops, fix your right arm position. Your left hand must be free to move, not busy holding the guitar up.
8. Shoulders **down and relaxed.** Check this every few minutes. Beginners creep their shoulders up toward their ears.

### Common posture mistakes
| Mistake | Problem | Fix |
|---|---|---|
| Guitar tilted back to see the fretboard | Wrist bends awkwardly and fingers can't arch | Keep the guitar upright and peek over the edge |
| Slouching or hunching | Back pain, shallow breathing, weak voice | Sit on the front of the chair, tall spine |
| Sofa or bed | The guitar sinks and your posture collapses | Use a chair |
| Neck pointing down | Left wrist over-bends | Angle the neck up |
| Left hand holding up the guitar | Fingers can't move freely | Right forearm + thigh hold the guitar |
| Crossed legs | Can be fine, but often twists the spine | Start with feet flat |

### Standing (optional, Week 4)
Use a strap. Adjust it so the guitar sits at **the same height as when you're sitting**, around your belt line, with the soundhole roughly at your elbow. Low-slung "rockstar" height makes chords harder.

## 5. The fretting hand (left hand)

### Finger numbers
| Finger | Number |
|---|---|
| Index | **1** |
| Middle | **2** |
| Ring | **3** |
| Pinky | **4** |
| Thumb | **T** (you won't fret with it this month) |

### The five rules of clean fretting
1. **Press with the very tip of your finger**, the bony tip, not the flat pad. Your fingers should look like arches (like holding a ball), coming down onto the string from above.
2. **Press just behind the fret**, close to the metal fret strip on the side nearer your body, **not** in the middle of the space between frets, and not on top of the fret. Near the fret = less pressure needed and no buzz.
3. **Keep your nails short**, otherwise you can't press with the tip (see [Fingernails](#fingernails)).
4. **Thumb behind the neck**, roughly behind your middle finger, pad of the thumb on the back of the neck, pointing up toward the ceiling. The thumb and fingers squeeze gently like a clothespin. (Some players let the thumb peek over the top of the neck for G. That's fine as long as the fingers stay arched.)
5. **Use only as much pressure as you need.** Beginners press 3–4× harder than necessary, which causes fatigue and pain. **Exercise:** fret a note, pluck it repeatedly, and slowly release pressure until it buzzes, then add back just enough to ring clean. That's the amount you need.

### Wrist and palm
- Keep your wrist fairly **straight**, not sharply bent.
- Leave **a gap between your palm and the bottom of the neck**. You should be able to see light through it. If your palm is pressed against the neck, your fingers go flat and mute strings.

### Muted strings: the #1 beginner problem
If a string sounds "dead" or "thunks" in a chord, **another finger is touching it.** Check:
- Are your fingers arched enough? The underside of a finger may be leaning on the next string.
- Are you on your fingertips?
- Is your palm touching the neck?

Diagnose by **plucking each string of the chord one at a time**, from 6 to 1. Find the dead one, figure out which finger is touching it, and adjust.

<a id="fingernails"></a>
### Fingernails
- **Fretting-hand (left) nails: short**, trimmed so you can't see the nail when you look at your fingertip from the palm side. Long nails hit the fretboard and push your fingers onto their pads.
- **Strumming-hand (right) nails:** any length. Slightly longer nails can help if you strum without a pick.

## 6. The strumming hand (right hand)

### Holding a pick
1. Hold your right hand in a loose "thumbs up."
2. Curl your index finger so its side (the outside of the first knuckle) faces up.
3. Lay the pick **flat on the side of the index finger's first joint**, pointy end aimed out, **perpendicular** to the finger.
4. Press your **thumb** down flat on top of the pick.
5. Only about **2–3 mm (1/8 inch)** of the tip should stick out.
6. Grip **firmly enough that it doesn't fly out, loosely enough that it can flex slightly.** Slightly loose is better than tight.
7. Other fingers: relaxed and curled, or loosely open. Either way is fine, as long as they're not tense.

**Pick keeps turning in your fingers?** Totally normal in Week 1. Grip a little firmer, show less tip, or try a pick with a grippy texture (e.g. Dunlop Tortex, or picks with a raised grip).

### Picks vs. thumb vs. fingers
- **Pick (recommended for Month 1)**: brighter and clearer, and most beginner strumming lessons assume one.
- **Thumb strumming** (brush down with the side of your thumb, up with your index nail): warmer, softer sound. It works really well for "Ain't No Sunshine" and is closer to the mellow sound of the record. Try it in Week 4 as an option.

### Strumming motion
- The motion comes mostly from the **forearm rotating** (like shaking water off your hand, or turning a doorknob), plus some **wrist**, and very little from the elbow or shoulder.
- Strum **over the soundhole, or just where the neck meets the body.** Near the neck = warmer and softer; near the bridge = brighter and thinner.
- **Down-strums** go toward the floor, hitting the thick strings first. **Up-strums** go toward the ceiling, hitting the thin strings first. Up-strums usually only catch the top 3–4 strings, and that's correct.
- Keep the pick **angled slightly**: tilt the leading edge a little so it glides through the strings rather than hitting them flat. This makes strumming smoother and quieter.
- **Relaxed.** A tense arm makes a harsh, uneven strum.

### Aiming: which strings to hit
| Chord | Lowest string to strum from |
|---|---|
| **Em** | 6 (all six strings) |
| **G** | 6 (all six) |
| **Am** | 5 (skip the low E) |
| **Dm** | 4 (skip the low E and A) |

In Week 1–2 don't worry much about aiming, just strum. By Week 3, try to start Am on string 5 and Dm on string 4. Hitting extra bass strings on those chords makes them sound muddy. (Adding the wrong bass note occasionally is a small crime, not a big one.)

## 7. Reading fret codes

Every chord in this course is written as a one-line **fret code**: six characters, one per string, from the low E (string 6) to the high e (string 1).

- A **number** = press that string at that fret.
- **0** = play the string open (unfretted).
- **x** = don't play that string.

`Am = x02210` means: string 6 not played, string 5 open, string 4 fret 2, string 3 fret 2, string 2 fret 1, string 1 open.

Each chord below also lists which finger goes where (1 = index, 2 = middle, 3 = ring, 4 = pinky).

## 9. Your four chords (plus helpers)

These are the only chords in "Ain't No Sunshine." Learn them in this order: **Em → Am → G → Dm.**

### Em (E minor): `022000` — the easiest chord on the guitar
- **Finger 2** (middle): string 5 (A), fret 2
- **Finger 3** (ring): string 4 (D), fret 2
- Strum **all 6 strings**.
- Some people prefer fingers 1 + 2. Use 2 + 3, because it makes switching to Am much easier (your fingers just shift down one string each).
- Sound: dark, deep, a bit sad.

### Am (A minor): `x02210`
- **Finger 1** (index): string 2 (B), fret 1
- **Finger 2** (middle): string 4 (D), fret 2
- **Finger 3** (ring): string 3 (G), fret 2
- Strum **strings 5 to 1** (skip the low E).
- **Em → Am shortcut:** Em's fingers 2 and 3 each move **down one string** (toward the floor), and finger 1 drops onto the B string, fret 1. It's the same shape shifted.
- Common problem: finger 1's underside mutes the high e string. Arch it more.
- **This is the home chord of "Ain't No Sunshine."** You'll play it more than any other.

### G (G major): `320003`, full version
- **Finger 2** (middle): string 6 (low E), fret 3
- **Finger 1** (index): string 5 (A), fret 2
- **Finger 3** (ring): string 1 (high e), fret 3
- Strum **all 6 strings**.
- It's a stretch. Keep your thumb low behind the neck, and push your wrist slightly forward (away from you), under the neck.

**Alternative G fingering (`320033`, "rock G" / "Cadd9-friendly G"):** 2 on string 6 fret 3, 1 on string 5 fret 2, 3 on string 2 fret 3, 4 on string 1 fret 3. It sounds fuller. Try it in Month 2.

**Easy G (Week 1–2 fallback): `xx0003` or `320003` with fewer strings**
- Just **finger 3** on string 1, fret 3, and strum **strings 4 to 1 only**.
- It's a real G chord (thinner-sounding). Use it without shame while the full G develops. **Switch to full G by the start of Week 3 if you can.**

### Dm (D minor): `xx0231`
- **Finger 1** (index): string 1 (high e), fret 1
- **Finger 2** (middle): string 3 (G), fret 2
- **Finger 3** (ring): string 2 (B), fret 3
- Strum **strings 4 to 1 only**.
- It's a small, compact "triangle" shape. The most common problem is **finger 3 leaning on string 1** and muting it. Arch finger 3 up so it only touches string 2.
- Sound: sad, sweet, dramatic. It's the emotional peak of each verse.

### Helper: Em7 (E minor 7): `020000`, the one-finger version
- Just finger 2 on string 5, fret 2.
- Many chord charts for this song use **Em7** instead of Em. It's a softer, jazzier version and it's even easier. Use either one. Em7 is closer to the record's feel.

### The chord summary table

| Chord | Fret code (6→1) | Fingers | Strum from string | Difficulty | Learn in |
|---|---|---|---|---|---|
| Em | `022000` | 2, 3 | 6 | ★☆☆☆ | Week 1 |
| Em7 | `020000` | 2 | 6 | ★☆☆☆ | Week 1 |
| Am | `x02210` | 1, 2, 3 | 5 | ★★☆☆ | Week 1 |
| G (easy) | `xx0003` | 3 | 4 | ★☆☆☆ | Week 2 |
| G (full) | `320003` | 1, 2, 3 | 6 | ★★★☆ | Week 2 |
| Dm | `xx0231` | 1, 2, 3 | 4 | ★★★☆ | Week 2 |

## 10. Changing chords

**Changing chords, not playing chords, is the real skill.** Almost any beginner can play one chord cleanly given 10 seconds. The song gives you less than 1 second.

### Technique 1: Move all fingers as a unit
Don't place fingers one at a time ("finger 1… now finger 2… now 3"). Practice lifting the whole shape together and landing it together. Picture the shape before you move.

### Technique 2: Anchor and guide fingers
Look for fingers that **stay put** (anchors) or **slide along the same string** (guides) between chords.
| Change | Shortcut |
|---|---|
| Em → Am | Fingers 2 and 3 keep the same shape and shift down one string. Add finger 1 |
| Am → Em | Lift finger 1, shift fingers 2 and 3 up one string |
| Dm → Am | Used in every verse. The G string, fret 2 is fretted in both chords (finger 2 in Dm, finger 3 in Am). Keep your hand in the same area and "roll" the shape rather than lifting away |
| Em → G | Finger 2 slides from string 5 fret 2 up to string 6 fret 3; finger 3 goes to string 1 fret 3, finger 1 to string 5 fret 2. (With **Em7** there are fewer fingers to move) |
| G → Am | The hardest move in the song. Practice it on its own |
| Em → Dm | No shared fingers. Practice the shape in the air |

### Technique 3: Lead with the bass
Place the finger that plays the **lowest string** first. You strum from the bass side, so it gives you a fraction of a second for the other fingers.

### Technique 4: The "open-string cheat" (a professional secret)
On the last up-strum before a chord change (the "and" of beat 4), **lift your fingers early** and let the strum hit open strings while your fingers travel. Everyone does this, and on a strummed song it's inaudible. Keeping the strumming hand going is more important than a perfect chord.

### The One-Minute Changes drill (do it daily from Day 3)
Popularized by guitar teacher Justin Sandercoe. It's the single most effective drill for chord changes.
1. Pick two chords (e.g. Em and Am).
2. Set a timer for **60 seconds**.
3. Strum each chord **once**, then switch: Em (strum), Am (strum), Em (strum), and so on.
4. **Count every successful change** (each landing counts as one).
5. Write the number in your log.
6. Don't worry about perfect sound during the drill. It trains the movement. Speed of the fingers is what counts.

**Targets:**
| Level | Changes per minute |
|---|---|
| Starting out | 5–15 |
| Playable in a slow song | 30 |
| Comfortable | 45 |
| Solid | 60+ |

Do 2–3 pairs a day. The log makes progress visible, which keeps you motivated.

### Other change drills
- **Air changes:** form the chord shape in the air above the fretboard, then land it. Lift, form, land. Trains the "memory" of the shape.
- **Eyes-closed changes:** once you're at 30+/min, do changes without looking.
- **Metronome changes:** 4 strums per chord at 60 BPM → 2 strums → 1 strum.

## 11. Strumming

### The golden rule: your hand never stops
Your strumming hand moves **down on the beat and up between beats**, continuously, like a pendulum, **whether or not you hit the strings.** To "skip" a strum, just move past the strings without touching them (a "ghost strum" or "miss"). This keeps your timing perfect.

### Counting 8th notes
```
Count:   1   &   2   &   3   &   4   &
Hand:    ↓   ↑   ↓   ↑   ↓   ↑   ↓   ↑
```
- **Numbers** (1, 2, 3, 4) = the beat = **down** motion
- **"&"** (and) = between beats = **up** motion

### The strumming patterns in this course (in order)

**Pattern 1 — Whole note ("one and let ring")**: Week 1–3, and when learning to sing along
```
Count:   1   &   2   &   3   &   4   &
Strum:   D   -   -   -   -   -   -   -
```

**Pattern 2 — Quarter notes (four downs)**: Week 1–2
```
Count:   1   &   2   &   3   &   4   &
Strum:   D   -   D   -   D   -   D   -
Hand:    ↓   ↑   ↓   ↑   ↓   ↑   ↓   ↑    ← up motions still happen, just miss the strings
```

**Pattern 3 — Eighth notes**: Week 2
```
Count:   1   &   2   &   3   &   4   &
Strum:   D   U   D   U   D   U   D   U
```

**Pattern 4 — "The Folk Pattern" (D – D U – U D U)**: Week 3–4, the main song pattern
```
Count:   1   &   2   &   3   &   4   &
Strum:   D   -   D   U   -   U   D   U
Hand:    ↓   ↑   ↓   ↑   ↓   ↑   ↓   ↑
                         ↑ miss (ghost down)
```
Say it out loud: **"DOWN, down-up, up-down-up."** It's the most used strumming pattern in pop, folk and rock. Learning it once pays off for years.

**Pattern 5 — "Slow Soul" (D – D U) × 2 with swing**: Week 4 option, closer to the record
```
Count:   1   &   2   &   3   &   4   &
Strum:   D   -   D   U   D   -   D   U
```
Play it **swung**: the "&" comes a bit late, "DAAA-da DAAA-da" rather than "da-da da-da." Listen to the record: the feel is loose, laid-back and swung.

### Dynamics (loud and soft)
- Downs slightly louder than ups.
- **Beat 1 slightly accented** (stronger).
- When singing, **strum softer than you think.** The voice is the star. If you can't hear yourself sing, the guitar is too loud.

### Palm muting (optional, Week 4)
Rest the edge of your strumming hand (the pinky side of your palm) lightly on the strings just in front of the bridge while strumming. You get a soft, percussive, "chunky" sound. It's good for the quiet "I know" section.

## 12. Using a metronome

A metronome clicks a steady beat. It exposes timing problems you can't hear yourself.

- **BPM** = beats per minute. 60 BPM = one click per second.
- **"Ain't No Sunshine" is roughly 76–80 BPM.** You'll practice slower (50–65) and work up.
- Put the click **on beats 1, 2, 3, 4**. Many apps can accent beat 1. Turn that on.
- **How to use it:** listen to 4 clicks before you start (count them out loud: "1, 2, 3, 4"). Then play, making your down-strum land **exactly on** the click so you can barely hear the click (it's "buried").
- **The +5 rule:** when you can play something 3 times in a row cleanly at a tempo, raise it by 5 BPM.
- **When you mess up,** drop back 10 BPM.

## 13. Fingertips, callouses and care

### What happens
- **Days 1–4:** fingertips sting, and you see string grooves on them.
- **Days 5–14:** soreness, sometimes a slightly numb or "tight" feeling in the tips. Skin starts thickening.
- **Weeks 2–4:** callouses form (hard, slightly shiny, sometimes yellowish skin on the tips). Pain fades.
- After 4–6 weeks: they don't hurt at all.

### How to build callouses without injury
- **Short, frequent sessions** (2 × 15 minutes beats 1 × 60 minutes early on).
- **Stop when fingertips hurt sharply** or when you see a blister forming. You'll lose days if you push through.
- **Don't soak your hands** in water for a long time right before playing (it softens skin).
- **Don't pick or peel callouses.** If one gets rough or snaggy, gently file it with a nail file or emery board.
- Extra-light strings help at the start.
- **Don't** use superglue, rubbing alcohol "hardening," or other internet tricks. They're unnecessary, and some are harmful.

### Hands and arms
- **Warm up**: 60 seconds of opening and closing fists, wrist circles, and gentle finger stretches (see [06 — Daily Routines](06-Daily-Routines.md)).
- **Shake out** your hands between exercises.
- **Stop** if you feel pain in the wrist, thumb base, or forearm, or tingling or numbness. Rest for a day. If it persists more than a few days, see a doctor or physiotherapist.

## 14. Looking after the guitar

- **Store** it on a stand or in its case, **away from** radiators, heaters, air-con vents, windows with direct sun, and car trunks. Big temperature and humidity changes can crack wood.
- Ideal humidity: **40–60%**. In dry winters, use a guitar humidifier.
- **Wipe the strings** with a dry cloth after playing. Sweat and skin oils kill strings fast.
- **Wash your hands** before you play. It keeps the strings alive much longer.
- Don't lean it against walls or chairs where it can fall. Headstocks snap easily.
- For travel, use a gig bag (padded) or a hard case.

## 15. Changing strings

You'll probably need to do this once this month or next (a string breaks, or they sound dull). Every 2–3 months is typical for regular players.

### Signs your strings need changing
- They sound dull or "thuddy" instead of bright and ringing
- They won't stay in tune
- They're discolored, rusty, or feel gritty
- One broke

### Basic steps (acoustic with bridge pins)
1. **Loosen** the string with the tuning peg until it's floppy.
2. Unwind it from the tuning post.
3. **Remove the bridge pin**, using the notch on a string winder (or gently with pliers, protecting the wood with a cloth). Pull out the string.
4. **Change one string at a time** (so the neck tension stays balanced and you can copy how the others are wound).
5. Put the **ball end** of the new string into the bridge hole, push the pin back in (**with the pin's groove facing forward, toward the neck**), and pull the string gently while pushing the pin down so the ball end locks against the pin, not the pin's tip.
6. Pull the string up to its tuning post. Leave about **2–3 inches (5–7 cm) of slack** past the post, then put the end through the post's hole.
7. Bend the string's end sharply to lock it, and wind it so the string wraps **downward** on the post, going toward the inside of the headstock.
8. Tune up to pitch. **Stretch the new string**: gently pull it away from the fretboard along its length, retune, and repeat 3–4 times. New strings stretch a lot. If you skip this, they'll go flat all session.
9. Clip the excess with wire cutters, leaving about 1/4 inch (6 mm).
