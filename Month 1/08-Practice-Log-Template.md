# 08 — Practice Log Template

A log turns vague "I think I'm getting better" into hard proof, and proof keeps you practicing. Fill one in every session. It takes 2 minutes.

> **In Notion,** you don't need this template: each day's page in the 📅 Daily Plan database has these fields built in (minutes, One-Minute Change scores, hiss, tempo, voice, good / fix tomorrow, pain), and the Daily Plan's chart views track your progress. Use this file if you're logging somewhere else.

---

Copy this block for each session.

```
### Day __ — Date: ____________
Week: __   Session length: ___ min   Energy (1–5): __

GUITAR
- Chords worked on:
- One-Minute Changes:
    Em↔Am: ___   Am↔G: ___   Em↔G: ___
    Em↔Dm: ___   Dm↔Am: ___  Am↔Dm: ___
- Strum pattern / tempo (BPM): ________
- Song section(s) played: ________

VOICE
- Hiss time (seconds): ___
- Warm-ups done: A / B / C
- Pitch/ear work: ________
- Voice felt: fresh / fine / tired / hoarse

TOGETHER
- Layering step reached (1–8): ___
- What I sang/played together: ________

RECORDING
- Recorded: yes / no — filename: ________
- One thing that was good:
- One thing to fix tomorrow:

PAIN / DISCOMFORT (fingers, wrist, voice): ________
```
